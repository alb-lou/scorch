# Scorch (working name)

A saturation plugin (AU, VST3, Standalone) with five original saturation models, built with JUCE.

Styles: Tape Tube, Console, Germanium, Triode, Pentode.
Controls: Drive, Punish, Tone, Low Cut, Thump, High Cut, Steep (12 dB/oct high cut), Mix, Output,
Auto Gain (static compensation) and Calibrate.

## Get a Mac build without installing anything (GitHub Actions)
1. Create a free GitHub account and a new empty repository.
2. Upload this whole folder to it (keep the `.github` folder - it contains the build recipe).
3. Open the **Actions** tab, pick **Build Scorch (macOS)**, and wait ~10-15 minutes
   (**Run workflow** if it didn't start by itself).
4. Open the finished run and download the **Scorch-macOS** artifact (a zip).

## Install on macOS
- AU:   copy `Scorch.component` to `~/Library/Audio/Plug-Ins/Components/`
- VST3: copy `Scorch.vst3` to `~/Library/Audio/Plug-Ins/VST3/`
- The build is unsigned (ad-hoc). If macOS blocks it, run in Terminal:
  `xattr -cr ~/Library/Audio/Plug-Ins/Components/Scorch.component ~/Library/Audio/Plug-Ins/VST3/Scorch.vst3`
- Logic: Settings > Plug-in Manager > rescan if it doesn't appear. Ableton: use VST3 or AU.

## Build locally (Xcode command line tools + CMake)
    cmake -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_OSX_ARCHITECTURES="arm64;x86_64"
    cmake --build build --config Release

## Auto Gain and Calibrate
Auto Gain applies a fixed gain offset (no detector, so no dynamics are added). It starts from a built-in
table measured on pink noise at -18 dBFS RMS. Press **Calibrate**, play your loudest section, press it
again, and the plugin stores a measured offset for the current settings. Changing style, drive, punish,
tone or the filters drops back to the built-in curve. **Reset** clears the calibration.

## Files
- `Source/Dsp.h`            DSP core (plain C++, no JUCE)
- `Source/AutoGainLut.h`    generated by `tests/dsp_test.cpp` (re-run it after changing the DSP)
- `Source/Plugin*.{h,cpp}`  JUCE processor and editor
- `tests/dsp_test.cpp`      harmonic / stability / auto-gain generator
  (`cd tests && g++ -O2 -std=c++17 dsp_test.cpp -o dsp_test && ./dsp_test`)

## Notes
All models are original, built from public circuit behaviour. The voicing is untuned against any
commercial product. Pro Tools (AAX) is not included.
